## Above the tool

### Intro (hero)

A code on the display is the appliance telling you where it thinks the problem is. Pick the appliance and the brand, type the code the way it shows, and the decoder gives you the usual meaning in plain words, the most likely cause, the checks that are safe to do yourself, and when to stop using it. It holds 116 common codes from Samsung, LG, Whirlpool, GE, Bosch, Frigidaire and the other names common around Temple.

### Before you type (three tips)

- **Copy it exactly.** Letters, numbers and the order they flash in. "5E" and "E5" can be different faults.
- **Pick the right brand.** The same letters mean different things on different brands, and a Kenmore often uses the codes of whoever built it.
- **Note when it shows up.** At the start of a cycle, halfway through, or only now and then. That changes the advice.

## Below the tool

### What each part of the result tells you

- **What this code usually means.** The fault the brand has published for that code, in plain words.
- **Most likely cause.** The part or condition that triggers it most often. It's a starting point, not a verdict.
- **Safe first checks.** Things you can look at without tools or opening panels: a filter, a hose, the door, a reset.
- **When to stop using the appliance.** If this part says stop, stop. Running a washer with a jammed pump or a dryer with a blocked vent can turn a small repair into a bigger one.
- **Recommended next step.** Whether to watch it, plan a repair or call today.

### Severity, in plain terms

| Severity | What it means for you |
|---|---|
| Low | Usually a setting, a filter or a load problem. Try the safe checks and watch whether it comes back. |
| Medium | A part is likely starting to fail. Plan a repair soon, before it quits at a bad moment. |
| High | Don't wait on it. Call the same day and keep using it only if the result says that's safe. |
| Critical | Switch it off and leave it off. Call and say it's urgent. |

### When the code isn't in the decoder

It tells you so instead of guessing. Write down the full model number, check the owner's manual, and try one power reset by flipping its breaker off, counting to sixty and flipping it back. If the code comes straight back, describe what the appliance is doing in [the symptom checker](https://appliancerepairtemple.com/appliance-symptom-diagnostic-tool/) instead, since symptoms often say more than an unlisted code.

### A note on Samsung and LG

Both brands lean heavily on codes and on their phone apps, and both reuse short codes across washers, dryers and fridges. If yours is one of them, [Samsung's common faults and codes](https://appliancerepairtemple.com/brands/samsung-appliance-repair-temple-tx/) and [what LG's codes usually point to](https://appliancerepairtemple.com/brands/lg-appliance-repair-temple-tx/) go further than the decoder can.

### Safety

A code never outranks what you can see or smell. Gas, smoke, sparks, a shock or water near wiring override any code: switch the appliance off and deal with that first. With gas, get out first and ring 911 or the gas utility once you're clear of the house.

## FAQ (rewritten; none of these questions appear elsewhere on the site)

### Why does the same code mean different things on different brands?

Because each manufacturer writes its own list. OE is a drain fault on an LG washer, while an F code on a GE oven and one on a Frigidaire oven point to different problems. That's why the decoder asks for the brand first. A Kenmore often uses its maker's codes, so the prefix on its model tag is worth checking.

### My code isn't in the decoder. What now?

Write down the full model number and look the code up in the owner's manual, which usually lists the brand's codes near the back. Try one power reset at the breaker. If the code returns, call with the code and the model number, and say whether it shows at the start of a cycle or partway through.

### Should I reset the appliance to clear a code?

Once, after you've done the safe checks. Cutting the power at the breaker for about a minute clears many codes once the cause is gone. If the code comes straight back, stop resetting it; clearing a code without fixing the cause can let a small fault turn into a bigger one.

### The code comes and goes. Does that matter?

Yes, it's a clue. A code that shows up only now and then often points to a loose connector, a sensor near the edge of its range, or a restriction that only builds up on long cycles. Choose "It keeps coming back" in the decoder, and mention the pattern when you call.
